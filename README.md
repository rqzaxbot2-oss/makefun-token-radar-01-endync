# Token Launch Radar — pre-token protocol value board

[![make.fun · token-radar-01](https://make.fun/badge/token-radar-01.svg)](https://make.fun/bounty/token-radar-01)
[![rank](https://make.fun/badge/token-radar-01/{owner}/{repo}/rank.svg)](https://make.fun/bounty/token-radar-01/leaderboard)

Reads a sealed DefiLlama snapshot, finds protocols with no token that aren't wrapped/staked derivatives, ranks them by implied launch value, and ships a static dashboard with board, per-protocol detail and farm plans.

## Run it

```sh
node main.ts
```
