# Token Launch Radar — untokenized protocol board with implied value and farm plans

[![make.fun · token-radar-01](https://make.fun/badge/token-radar-01.svg)](https://make.fun/bounty/token-radar-01)
[![rank](https://make.fun/badge/token-radar-01/{owner}/{repo}/rank.svg)](https://make.fun/bounty/token-radar-01/leaderboard)

Ranks every DefiLlama protocol with no tradable token by what its launch would be worth, with a static dashboard: board, per-protocol detail, filters, and step-by-step farm plans.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
